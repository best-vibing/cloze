# 로드맵

서비스 전체에서 남은 일을 큰 틀로 정리한다. 개별 작업은 이슈와 PR에 있고, 이 문서는 순서와 묶음만 다룬다. 세부 내용은 여기에 옮겨 적지 않고 링크한다([README 문서 규칙](../README.md#문서-규칙) 1).

기준 시점: 2026-11-09. 열린 이슈 #12·#13·#14·#28~#32, 열린 PR #15~#23·#26·#27을 보고 정리했다. 닫힌 PR은 반영하지 않았다. 2026-11-26에 0·1장과, 끝난 항목의 "(완료·머지)" 표시만 고쳤다(머지된 PR 기준). 나머지 서술과 순서는 11-09 기준이다.

## 0. 지금 위치

```
PDF 업로드 → 추출 → 필터 → 빈칸 선택 → 품질 게이트 → 가리기 → 저장 → 풀이 화면 → 채점
             [머지] [머지]  [규칙·Gemini]   [머지]      [머지]   [PR]    [화면 머지]  [판정만]
```

- (2026-11-26) 추출부터 가리기까지와 Gemini 선택기·품질 게이트·쪽 파이프라인이 `develop`에 있다([#71](https://github.com/best-vibing/cloze/pull/71)~[#75](https://github.com/best-vibing/cloze/pull/75), [#106](https://github.com/best-vibing/cloze/pull/106), [#113](https://github.com/best-vibing/cloze/pull/113), [#114](https://github.com/best-vibing/cloze/pull/114)). 아직 API·워커에 연결되지 않아 CLI와 core 함수로만 돈다. 연결은 업로드 [#50](https://github.com/best-vibing/cloze/issues/50)와 워커 작업 [#52](https://github.com/best-vibing/cloze/issues/52)이 한다. 저장은 [#100](https://github.com/best-vibing/cloze/pull/100)·[#102](https://github.com/best-vibing/cloze/pull/102)가 리뷰 중이고, 풀이 화면은 Mock으로 붙어 있다([#115](https://github.com/best-vibing/cloze/pull/115)·[#121](https://github.com/best-vibing/cloze/pull/121)).
- 가중치와 기준값은 fixture로만 맞춘 [가설]이다. 실제 강의자료(Lec2.pdf)로 돌려 보니 빈칸 68개 중 24개(35%)가 의미 없는 글이었다([#31](https://github.com/best-vibing/cloze/issues/31)).
