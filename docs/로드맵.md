# 로드맵

서비스 전체에서 남은 일을 큰 틀로 정리한다. 개별 작업은 이슈와 PR에 있고, 이 문서는 순서와 묶음만 다룬다. 세부 내용은 여기에 옮겨 적지 않고 링크한다([README 문서 규칙](../README.md#문서-규칙) 1).

기준 시점: 2026-11-09. 열린 이슈 #12·#13·#14·#28~#32, 열린 PR #15~#23·#26·#27을 보고 정리했다. 닫힌 PR은 반영하지 않았다. 2026-11-11에 0·1장(엔진 머지 상태)만 고쳤다.

## 0. 지금 위치

```
PDF 업로드 → 추출 → 필터 → 빈칸 선택 → 품질 게이트 → 가리기 → 저장 → 풀이 화면 → 채점
             [PR]   [PR]   [규칙만, PR]    [없음]      [PR]    [논의 중]  [시작 전]   [시작 전]
```

- 추출부터 가리기까지는 CLI(`select`, `mask`)로 돌아간다. 스택 PR은 2026-11-11에 모두 머지됐지만 base를 바꾸지 않은 채 머지돼 `develop`에는 들어가지 않았다. 복구는 [#71](https://github.com/best-vibing/cloze/pull/71)이 한다.
- 가중치와 기준값은 fixture로만 맞춘 [가설]이다. 실제 강의자료(Lec2.pdf)로 돌려 보니 빈칸 68개 중 24개(35%)가 의미 없는 글이었다([#31](https://github.com/best-vibing/cloze/issues/31)).

- 아래 PR부터 머지하고, 머지할 때마다 바로 위 PR의 base를 `develop`으로 바꾼다([CONTRIBUTING 4절](../CONTRIBUTING.md)).

## 2. 실제 강의자료 품질 맞추기

엔진이 fixture에서는 맞지만 실제 자료에서는 부족하다.

- 의미 없는 글 빼기: 바닥글·표지의 과목명과 이름([#31](https://github.com/best-vibing/cloze/issues/31)), 표지·목차 같은 쪽([#32](https://github.com/best-vibing/cloze/issues/32))
- 아직 이슈가 없는 것(출처: #27 확인 코멘트, 각 PR의 "결정 필요")
  - 한국어 토큰이 띄어쓰기 없이 붙음(추출 `x_tolerance`)
  - 붙은 두 단어가 빈칸 하나로 보임(선택 단계)
  - 정답·칠한 자리에 문장 부호와 조사가 섞임
- [가설] 값 보정: 실제 강의자료 여러 개로 [selection-and-quality-gate.md](design/selection-and-quality-gate.md) 2.5절 절차를 돌린다.

- Gemini 선택기([ADR-010](decisions/ADR-010-llm-gemini.md))
