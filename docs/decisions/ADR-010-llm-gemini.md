# ADR-010: LLM — Gemini API 무료 티어

## 상태
채택됨 (2026-10-28). 기본 모델은 1주차 실측 후 확정

## 컨텍스트

LLM은 페이지마다 가릴 단어를 고르고, 자동 모드에서 자료 유형을 판단한다([단어 선택·품질 게이트](../design/selection-and-quality-gate.md)). 필요한 것은 다음과 같다.

- 한국어·영어 PDF를 모두 다룬다.
- 구조화 출력(JSON 스키마)으로 답을 받는다.
- 수업 프로젝트라 비용이 없어야 한다.
- 원래 앱이 Gemini를 쓰고 있어 클라이언트 코드를 재사용한다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| **Gemini API 무료 티어** | 공식 무료 티어가 있음. 한·영, 구조화 출력, 이미지 입력 지원. 원래 앱 코드 재사용 | 무료 티어 입력은 Google 제품 개선에 쓰임. 한도가 문서에 없고 AI Studio에서 프로젝트별로만 보임. 계정에 따라 쓸 수 있는 모델이 다를 수 있음 |
| OpenAI·Anthropic API | 품질 좋음 | 상시 무료 티어가 없어 비용이 생김 |
| Groq·OpenRouter의 무료 공개 모델 | 무료 | 한국어 품질과 구조화 출력 지원이 모델마다 불확실. 무료 호출 수가 적음 |
| 로컬 모델(Ollama 등) | 무료, 데이터가 밖으로 안 나감 | 시연 기기(RAM 15.7GB)에서 한국어 품질과 속도가 부족할 것으로 예상(측정 안 함) |

## 결정

Gemini API 무료 티어를 쓴다. 모델 이름은 설정 `CLOZE_GEMINI_MODEL`로 바꿀 수 있게 두고, 기본값은 `gemini-3.5-flash-lite`로 한다.

- 공식 문서는 Gemini 2.5를 당분간 계속 제공한다고 하면서도, 새 프로젝트에는 3.5 Flash-Lite나 3.8 Flash를 권한다.
- 팀원의 다른 프로젝트 기록에서 새 계정은 `gemini-2.5-flash` 호출이 404였고, 최신 모델만 동작했다.
- Flash-Lite가 품질 게이트를 자주 통과하지 못하면 `gemini-3.8-flash`로 바꾼다.

## 결과

- **1주차 확인:** 팀 키로 기본 모델을 실제 호출해 본다. AI Studio에서 분당·하루 한도를 읽어 [신뢰성 설계](../design/reliability.md)의 한도 초기값에 반영한다.
- **데이터:** 사용자가 올린 PDF 내용이 Google로 가고, 무료 티어라 제품 개선에 쓰일 수 있다. 시연에서는 샘플 PDF만 쓰고, 업로드 화면에 "외부 AI 서비스로 전송됨"을 표시한다.
- Gemini 장애나 키·모델 오류가 나면 규칙 기반 선택기로 폴백해 결과는 나온다. 서비스 전체 하루 호출 상한을 넘으면 폴백하지 않고 새 작업을 거절한다([아키텍처](../architecture.md) 2장 실패 처리·비용 상한).

## 재검토 조건

- 실제 사용자 자료를 받는 서비스로 바꾸면 유료 티어나 Vertex AI로 옮긴다(입력이 제품 개선에 쓰이지 않음).
- 무료 한도로 시연 규모(발표 설정)를 감당하지 못하면 다른 무료 제공자를 다시 검토한다.
